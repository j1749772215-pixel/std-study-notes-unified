# std-study-notes-unified

> **课程与真题 Obsidian 高可读彩色笔记统一规范（Windows / Mac 跨端共同维护版）**

本仓库专门用于统一管理四六级（写作、听力）及视频课程的 Obsidian 笔记成稿标准，包含：

- [`std-study-notes-unified/SKILL.md`](./std-study-notes-unified/SKILL.md)：统一 Skill 规范（可读性第一 + 完成态板书裁切逐笔拆解 + 兼容 Blue Topaz 的柔和彩色填充卡片模板）
- [`std-study-notes-unified/assets/cet4-rich-notes.css`](./std-study-notes-unified/assets/cet4-rich-notes.css)：Obsidian 全库彩色填充 CSS 代码片段（恢复 Callout、表格表头与 `==高亮==` 的柔和彩色底）

## 快速使用（Mac / Windows 通用）

### 1. 拉取 / 同步最新规范

```bash
git clone https://github.com/j1749772215-pixel/std-study-notes-unified.git
# 后续更新：
git pull
```

### 2. 在 Obsidian 中启用全库彩色填充 CSS

1. 将 `std-study-notes-unified/assets/cet4-rich-notes.css` 复制到你的 Obsidian 库目录：
   `<你的Vault>/.obsidian/snippets/cet4-rich-notes.css`
2. 打开 Obsidian **设置 → 外观 → CSS 代码片段**，开启 `cet4-rich-notes`。

### 3. 让任意对话线程（写作 / 听力 / Mac 端）按本规范共同维护

直接把下面这句话发给对应线程即可：

> 请先阅读 `std-study-notes-unified/SKILL.md`（或在线版 `https://raw.githubusercontent.com/j1749772215-pixel/std-study-notes-unified/main/std-study-notes-unified/SKILL.md`），后续所有笔记统一按这份规范执行与共同维护。
