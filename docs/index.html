一、v2 融合思路：为什么既要丰富色彩，又要轻量高级感？

Windows 写作卷 1 赢在视觉锚点强、色彩饱满好扫读；Mac 翻译样张赢在微组件疏密有致、CSS 变量克制统一。v2 把两者合成同一套标准。

Windows 强项 · 饱满语义大卡

用靛蓝导读、青蓝「看图拆板书」、翡翠绿实操、珊瑚红避坑、暖杏示范、淡紫我理解 6 色卡片，在长文里一眼锚定重点，彻底告别 Blue Topaz 白底黑字。

Mac 强项 · 轻量微组件语法

用 CSS Flexbox 并排卡、counter-reset 自动圆圈编号、inline-flex 上下对齐词块和 CSS 变量换肤，减少大块堆砌、让节奏更轻盈。

双端拍板 · 一份统一 CSS

把全套组件合入 cet4-unified.css（含柔和灰蓝 code、暗色模式、移动端自适应、100% 兼容 Mac 卷 0–7 旧 class）。

二、v2 融合成品实景（大块用饱满彩卡 × 细节用轻量微组件）

📌 卷首导读（Windows 招牌 · 靛蓝渐层卡）
3 句话讲清本卷解决什么问题：先定 核心概念，再落到 定稿英文，全段最关键一句用 荧光黄高亮 点睛。
① 审题抓信号› ② 替换中心词› ③ 定 3 个氛围词› 套进 5 句话
🖍️ 看图拆板书（Windows 招牌 · 清透青蓝卡，紧跟每张完成态板书图）
红圈 essay 看到 to write an essay 就定性议论文，不写标题直接开写第一段。
蓝线三段对应 第一段目录报出 3 个方向，第二段严格按同顺序展开，第三段一句话收尾。
✗ 考场高频错法（Mac 并排对比卡）
you will insufficient
can attribute to he is a student
情态动词漏 be；主被动用反 + 介词后硬接整句
✓ 零失误改法
you will be insufficient（或 fail to）
can be attributed to his being a student
两套颜色不打架：错法统一红删线 / ✗ 卡，定稿用绿底
中文 我主语 上周一状语 坐飞机状语 去了谓语 北京宾语
英文 I主语 went谓语 to Beijing宾语 by flight last Monday状语整块后移
✅ 交卷前 2 分钟的三遍检查法（Windows 薄荷翡翠绿卡）
1. 只查动词：查双谓语（is ... be）与漏 be；2. 只查介词和 its / it's；3. 数一遍字数跨过 120 词。
✍️ 手把手替换示范（Windows 暖杏琥珀卡）
把中心词从 translation app 换成 online library，把 3 个氛围词换成 study / efficiency / remote book resources，整篇 80% 以上的英文骨架根本没动。
先定第二段三层，再回头填第一段：保证目录与展开顺序严丝合缝（Mac 圆圈编号步骤条）。
批量替换中心词：圈出题面 on / about 后的核心名词短语。
固定词句一字不改：把脑力全留给贴合话题的氛围词。
坑第 3 句里的 bringing ... 千万不能删掉 -ing，否则一句话双谓语打架。
记128 词已经跨过 120 词底线，千万别在开头加空话「大帽子」。
补整理者自己补充的过渡或反例，统一用本卡片显式标注，不冒充老师原话。
老师原话　四级 P01　12:47（双端统一折叠在 <details> 内的深蓝原话卡）
